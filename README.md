# 盒宇宙 BOXVERSE

> 你的潮玩收藏宇宙，每一次拆盒都有惊喜。

一款原生安卓（Kotlin + Jetpack Compose + Material 3）潮玩盲盒收藏 App：实物收藏图鉴、虚拟拆盲盒、成就等级、收藏价值统计、心愿清单、重复款交换卡、2D 收藏展示柜，完全离线可用。

## 📥 下载安装（给普通用户）

1. 打开本仓库的 **Releases** 页面（仓库首页右侧 “Releases”，或访问 `https://github.com/qvbalf73-lgtm/Bobjobs/releases`）。
2. 在最新版本下方的 **Assets** 中点击 `BoxVerse-v1.0.x.apk` 下载。
3. 在手机上打开下载好的 APK。第一次安装时，系统会提示“是否允许安装未知来源应用”，选择 **允许 / 设置 → 允许此来源**。
4. 安装完成后，桌面会出现「盒宇宙」图标。
5. 以后有新版本，直接下载新的 APK 覆盖安装即可（数据会保留）。

> 每次向仓库推送代码，GitHub Actions 都会自动编译并发布新的 APK（见 `.github/workflows/build-apk.yml`）。

系统要求：Android 8.0（API 26）及以上。

## ✨ 功能一览（第一阶段 + 部分第二、三阶段）

| 模块 | 已实现 |
| --- | --- |
| 首页收藏中心 | 头像昵称等级、问候、签到、收藏总数/款式/完成系列/隐藏款、总成本/估值/盈亏、最近获得、每日任务、推荐系列、快捷入口（数据全部来自本地数据库） |
| 潮玩图鉴 | 品牌 / IP / 系列 / 款式四级结构；系列进度（如 8/12、67%）；已收藏彩色、未收藏灰色剪影 + 锁；搜索、筛选（收藏状态、品牌、实物状态）、排序；详情页图片画廊 |
| 实物收藏 | 新增 / 查看 / 编辑 / 删除；同款多件分别记录数量；单价、币种、物流及其他成本、日期、渠道、手动估价、状态、成色、原盒、评分、故事；拍照与相册导入；售出记录与已实现盈亏 |
| 虚拟拆盲盒 | 系列选择与介绍、摇晃 → 发光 → 开启 → 粒子 → 揭晓动画；R / SR / SSR / UR 四档专属光效，隐藏款特殊动画、闪光与合成音效；1 / 5 / 10 连开；按系列配置概率并强制总和 100%；概率公示；开盒记录与实际/设定概率统计；虚拟收藏柜；分享结果图 |
| 成就与等级 | 19 枚成就（解锁条件、进度、解锁时间）；Lv.1 潮玩新人 → Lv.50 盒宇宙传奇；经验完全由真实行为推导 |
| 价值统计 | 总成本、估算价值、未实现/已实现盈亏、品牌金额环形图、系列数量条形图、近 12 个月支出柱状图、最贵 TOP10 |
| 多币种 | CNY / SGD / MYR / USD / HKD；不联网、不伪造汇率，未手动设置汇率的币种单独列出不计入合计 |
| 心愿清单 | 目标价、数量、优先级、备注、已购入状态、一键转为实物收藏 |
| 重复款交换 | 自动列出持有 ≥2 的款式，设置可换数量、想换款式、成色、原盒、备注，生成精美交换卡分享 |
| 收藏室 | 自定义名称、5 种背景主题、展示架/网格布局、按系列或品牌一键布置、大图查看、生成分享图 |
| 个人中心 | 昵称头像签名、明亮/深色/跟随系统、音效与震动开关、每日签到提醒通知、ZIP 备份与恢复（含图片）、CSV 导出、演示数据一键清除/重新载入、清空数据、隐私说明、关于 |

**虚拟与实物严格隔离**：虚拟开盒结果存储在 `virtual_collection` / `blind_box_openings` 表，统计、估值、图鉴点亮只读取 `collection_items` 表。

## 🛠 技术架构

- Kotlin 2.0 · Jetpack Compose · Material 3 · MVVM · Navigation Compose
- Room（15 张表，导出 schema 至 `app/schemas`，`Migrations` 登记迁移，不使用破坏性迁移）
- DataStore（设置）· Kotlin Coroutines / Flow · Coil（图片）· kotlinx.serialization（备份）
- 业务逻辑（概率引擎、统计、等级、成就）位于 `domain` 包，纯 Kotlin，并有单元测试 `app/src/test`

```
app/src/main/java/com/boxverse/app/
├── domain/        # 纯业务逻辑：稀有度、概率引擎、金额与汇率、统计、等级与成就
├── data/db/       # Room 实体、DAO、数据库
├── data/repo/     # 仓库、演示数据、备份管理
├── data/prefs/    # DataStore 设置
├── ui/            # Compose 界面（theme / components / home / pokedex / blindbox / trade / profile …）
└── util/          # 图片存储、分享、音效、震动、提醒
```

## 本地编译（开发者）

需要 Android Studio（或 JDK 17 + Android SDK 35）：

```bash
./gradlew testReleaseUnitTest   # 运行单元测试
./gradlew assembleRelease       # 生成 app/build/outputs/apk/release/app-release.apk
```

演示内容中的品牌、角色与插画均为本 App 原创虚构（插画由代码绘制），不包含任何真实品牌的商标、图片或官方概率。
